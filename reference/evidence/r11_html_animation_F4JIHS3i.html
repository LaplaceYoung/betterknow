Pythagorean Theorem Proof

This visual proof uses the rearrangement method. We start with four identical right-angled triangles (sides a, b, and hypotenuse c) arranged inside a large square of side length (a + b).

Empty Area = c²
Empty Area = a² + b²

By shifting the triangles, we change the shape of the empty space without altering its total area. This demonstrates that c² = a² + b².
