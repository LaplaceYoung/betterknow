# 本仓与线上 Hyperknow 的差异说明

面向使用者（自部署的人），不是开发记录。开发口径的逐条差异在 `../spec/DESIGN_GAPS.md`，协议与样式来源在 `PROTOCOL.md` / `DESIGN_TOKENS.md`。

## 一句话

本仓把线上那套「AI 教学平台」在本机跑通：课程生成、白板课堂、语音提问、练习与考试、速查表编辑器、学习日程、知识库——**形状与文案对齐线上，模型能力换成你自己的 BYOK 网关，商业面与第三方链路去掉**。

## 一、能力对照

| 面 | 与线上一致 | 与线上不同 |
|---|---|---|
| 课程生成 | 四步进度、问卷、结构确认、生成完成后落运行记录并可回放 | 调研阶段用你配的 search 槽；没配则跳过联网（线上固定走它的检索） |
| 白板课堂 | 板书帧序、分步讲解、插图、TTS、打断答疑、侧栏三 tab、声音与倍速、网络自检 | 不做客户端 VAD（自托管模型）与真·实时 PCM 打断；说话是「按一次录、再按一次停」 |
| 语音 | 语音模式卡片、音色/语速设置、试听、状态文案 | 试听用的是**你自己配的音色**（线上放自带样本）；流式转写只有一条全量结果 |
| 练习 / 考试 | 计分口径（基础分 + 连对 + 速答 10s）、HUD 老虎机滚动、30 分钟倒计时、结果页 | 考试没有单独的快答窗口取值（线上未取证，沿用练习的 10 秒） |
| 速查表 | 三种模式（预览 / 正文 / 编辑）、工具栏与色板、3 秒自动保存、离开拦截 | 编辑器是 **markdown 文本域**而不是线上的 tiptap；锚点只作指示，不会「把 AI 生成的内容插到锚点行」 |
| 学习动态 | 日历（周/月、拖拽改期）、左栏三卡、「待处理」按来源分列 + 整列确认/拒绝、任务详情（含相关截止日期、文件卡三态、评论调整） | 待处理按「课程 / 无来源」分组（线上按 Canvas / 文件 / 公告）；「相关截止日期」按时间邻近推导（线上由服务端给关系） |
| 知识库 | 上传、文件夹、加入日历、可被引用 | 解析/摘要等后台任务不排期（线上会异步做） |
| 课程加入日历 | 服务端出稿 → 预览（可拖拽 / 全屏）→ 落库（替换语义） | 分配算法均摊（线上算法未取证） |
| 账户与额度 | 设置面板、用量展示、语言偏好 | 无登录墙（本机开放用户）、无积分扣费、无订阅/优惠券/Stripe |
| 团队与社交 | — | 无评论社交、分享页以外的协作面、无邮件与计费后台 |

## 二、有意去掉的东西

| 去掉的 | 原因 |
|---|---|
| 第三方埋点（intent pixel / Clarity） | 自部署不需要行为归因，也不该把使用数据发出去 |
| 错误上报到原站（`error/add_error_log`） | 同上；本地日志足够 |
| Stripe 结账、优惠券、积分与订阅 | 本仓没有商业面 |
| Google / Canvas OAuth | 需要厂商凭据与回调域名，自部署场景用不上 |
| 原站固定模型与检索 | 换成 BYOK 五槽（llm / tts / stt / search / image） |

## 三、BYOK 的五条通道

| 通道 | 用来做什么 | 不配会怎样 |
|---|---|---|
| llm | 对话、课程生成、白板讲解与答疑、出题、Agent 决策 | 用内置 stub 应答，界面照常可走通 |
| tts | 白板讲解语音 | 退回浏览器语音合成（帧里标 `stub: true`） |
| stt | 语音提问与打断转写 | 返回占位文本 |
| search | 课程生成的联网调研 | 跳过联网，直接进大纲 |
| image | 白板插图 | 出 SVG 占位图 |

判定「为什么是占位内容」先看帧里的 `stub` 字段；配好后可在设置面板点「测试」（浅探针打一次 `/models`，深探针真出图/真转写）。

## 四、数据与隐私

- 所有状态在一处：`hyperclone/server/var/data/`（`state.json` + `files/` / `tts/` / `whiteboard/` / `covers/` / `generation_runs/`）。删掉即重置。
- 运行时不向任何 hyperknow 域发请求：认证是本地签发，模型调用只走你配的网关，媒体文件落本地磁盘。
- 知识库上传的文件会连元数据一起落盘（`<id>.json`），删除知识库条目不会自动删磁盘文件——需要自己清 `var/data/files/`。

## 五、已知的取舍（会影响观感，但功能可用）

1. **速查表编辑器**是 markdown 编辑，不是富文本所见即所得；公式用 `$…$`，高亮用 `==…==`，文字颜色写入 `<span style>`。
2. **白板参考资料**一节恒为空态：本仓学习节没有 references 数据（线上来自课件解析）。
3. **任务详情没有「源文件卡」**：本仓任务模型里没有输入文件；每个子任务只产出**一份**学习材料。
4. **互动题**（带动画的题目）依赖题目自带的动画 HTML；本仓合成考试会给一道演示动画，线上题目的动画来自它的服务端。
5. **网络自检**没有 DNS/TLS 分项耗时，也没有独立的 `net_check_session` 专线。
6. **多语言**只覆盖界面（中文文案取自线上词典）；语言偏好影响的是**生成内容语言**。

## 六、如果要用到生产

- 单实例运行；两个进程指向同一 `var/data` 会互相覆盖（用 `HYPERCLONE_DATA_DIR` 分开）。
- 本仓的开放用户与本地 JWT 是为自部署准备的便利设计，**不要直接暴露到公网**；需要多用户请自行加认证与访问控制。
- 上传/分享类接口的行为对齐线上，但没有速率限制与配额——上线前自行加。
